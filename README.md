# Zustand Mini Shop Starter

이 저장소는 작은 쇼핑몰의 장바구니를 만들며 Zustand의 전역 상태와 액션을
배우는 starter입니다. 상품 목록, 장바구니, 헤더가 같은 상태를 읽고 수정하도록
강의 순서에 따라 하나의 프로젝트를 완성합니다.

## 처음 실행하면 보이는 화면

- 헤더에는 장바구니 수량이 `0개`로 표시됩니다.
- 상품 화면에는 네 개의 상품 카드와 `장바구니 담기` 버튼이 보입니다.
- 담기 버튼은 아직 동작하지 않고, 장바구니 화면은 비어 있습니다.

이 상태가 정상적인 시작 화면입니다. UI, 상품 데이터와 화면 전환은 이미
준비되어 있고, 장바구니 store와 액션은 아직 연결되어 있지 않습니다.

## 실행

```bash
npm install
npm run dev
```

## 시작 상태

- `Header.jsx`: 장바구니 수량이 `0`으로 고정되어 있습니다.
- `ProductList.jsx`: 담기 액션이 비어 있습니다.
- `Cart.jsx`: 장바구니 배열이 비어 있습니다.
- 같은 clone에서 강의 순서대로 변경을 누적합니다.
- 각 강의에서 지정한 `src` 파일과 TODO만 수정합니다. `styles.css`와
  `src/data/products.js`는 별도 안내가 없으면 제공 코드로 사용합니다.

터미널에 표시된 주소를 브라우저에서 열어 위 시작 화면이 보이면 준비가 끝난
것입니다.
