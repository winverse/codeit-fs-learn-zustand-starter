# Zustand Mini Shop Starter

`3-03. Zustand 적용 전 시작 상태`에 대응하는 starter입니다. UI와 상품 데이터는
준비되어 있지만 장바구니 상태와 액션은 아직 연결되어 있지 않습니다.

## 실행

```bash
npm install
npm run dev
```

## 시작 상태

- `Header.jsx`: 장바구니 수량이 `0`으로 고정되어 있습니다.
- `ProductList.jsx`: 담기 액션이 비어 있습니다.
- `Cart.jsx`: 장바구니 배열이 비어 있습니다.
- 각 TODO는 강의 순서에 따라 Zustand store로 교체합니다.
